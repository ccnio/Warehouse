📁 标准结构（单仓库多模块）

project-root/
│
├── annotation/               # 1️⃣ 注解定义（轻量级，无依赖）
│   ├── build.gradle.kts
│   └── src/main/kotlin/
│       └── com/company/annotation/
│           ├── MyAnnotation.kt
│           └── Generated.kt
│
├── processor/                # 2️⃣ KSP 处理器（代码生成）
│   ├── build.gradle.kts
│   └── src/
│       ├── main/
│       │   ├── kotlin/
│       │   │   └── com/company/processor/
│       │   │       ├── MyProcessor.kt
│       │   │       ├── MyProcessorProvider.kt
│       │   │       └── codegen/
│       │   │           └── CodeGenerator.kt
│       │   └── resources/
│       │       └── META-INF/services/
│       │           └── ...SymbolProcessorProvider
│       └── test/
│
├── plugin/                   # 3️⃣ Gradle 插件（ASM 字节码）
│   ├── build.gradle.kts
│   ├── settings.gradle.kts   # 独立 settings（如果用 includeBuild）
│   └── src/main/kotlin/
│       └── com/company/plugin/
│           ├── MyPlugin.kt
│           ├── MyExtension.kt
│           └── asm/
│               ├── ClassVisitorFactory.kt
│               └── MethodVisitor.kt
│
├── runtime/                  # 4️⃣ 运行时库（可选）
│   ├── build.gradle.kts
│   └── src/main/kotlin/
│       └── com/company/runtime/
│           └── RuntimeHelper.kt
│
└── sample/                   # 5️⃣ 示例应用
    ├── build.gradle.kts
    └── src/main/kotlin/
        └── MainActivity.kt

⚙️ 编译流程

1️⃣ KSP 阶段（processor）
   源代码 → KSP 扫描注解 → 生成新的 .kt 文件

2️⃣ Kotlin 编译阶段
   所有 .kt 文件 → kotlinc 编译 → .class 文件

3️⃣ Plugin ASM 阶段
   .class 文件 → ASM 字节码增强 → 最终 .class 文件

4️⃣ 打包阶段
   所有 .class 文件 → 打包成 APK/JAR

    id("com.company.myplugin") version "1.0.0"
}
